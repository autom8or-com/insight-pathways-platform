# App Flow Document

## Onboarding and Sign-In/Sign-Up

A new user arrives at the platform by visiting the public landing page, which briefly presents the purpose of the Insight Quizzing Platform and includes links to log in or sign up. When the user clicks "Sign Up," they land on a registration page where they enter their name, company email, and a password. The system validates the email format in real time and checks password strength before allowing submission. After submitting the form, the user receives an email confirmation link. Clicking that link activates their account and redirects them to the sign-in page. Existing users click "Sign In," enter their registered email and password, and submit. If the credentials match, the system issues a session token and sends the user to their role-specific dashboard. On the sign-in page, a "Forgot Password" link takes users to a recovery form where they enter their email. The platform sends a one-time reset link that leads to a secure page for choosing a new password. After resetting, the user can sign in with the new password. A "Sign Out" button is persistently available in the header or sidebar; clicking it ends the session and returns the user to the public landing page.

## Main Dashboard or Home Page

After signing in, the platform determines the user’s role—Respondent, Manager, Executive, or Admin—and displays the corresponding dashboard layout. A consistent header spans the top of every view, showing the app logo, the user’s name, and the sign-out control. A vertical sidebar on the left offers navigation links relevant to the user’s role. Managers see links for Content, Analytics, and Settings. Executives see Overview, Insight Pathways, and Settings. Respondents see My Quizzes and Settings. Admins see User Management, Roles & Permissions, and Settings. The center of the dashboard displays a welcome message and a summary widget or chart that highlights key metrics—such as pending quizzes for respondents, upcoming assignments for managers, enterprise-wide completion rates for executives, or recent user sign-ups for admins. From this main dashboard, users click on sidebar items to navigate deeper into features.

## Detailed Feature Flows and Page Transitions

When a Manager clicks the Content link, they are taken to a content management page that lists draft quizzes, scheduled quizzes, and published quizzes in a data table. Above the table is a button labeled "Create New Quiz." Clicking that opens a quiz editor page, where the Manager enters a quiz title, description, and due date. Inline controls allow adding questions of various types—multiple choice, open ended, scale rating—and previewing each question. A calendar icon opens a date picker for scheduling publication. A "Save Draft" button persists the quiz as a draft, while a "Publish" button activates it immediately and triggers serverless API calls to assign the quiz to selected respondent teams. A separate CSV upload link opens a modal where the Manager uploads a file of respondent emails; the system validates the CSV format, shows any errors inline, and then assigns new respondents to the quiz.

Respondents click My Quizzes in their sidebar to see assigned quizzes sorted by due date and status. Each quiz row shows a title, assigned date, due date, and a "Start Quiz" button. When the respondent clicks that button, the platform opens a full-screen quiz interface at the route `/take-quiz/[assignmentId]`. A top timer counts down the remaining time. Each question appears one at a time with navigation arrows. The system auto-saves answers after each question. Backtracking is disabled to preserve integrity. When the respondent reaches the last question, a "Submit Quiz" button appears. On submission, the system calculates the score, stores responses, and redirects to a confirmation page that thanks the respondent and informs them that personalized feedback will be emailed shortly.

For Executives and Managers who need analytics, clicking Analytics or Insight Pathways in the sidebar loads a responsive page with interactive charts and data tables. The default view shows a line chart of completion rates over time and a table breaking down rates by team or demographic. Filters at the top allow narrowing data by date range or team. Selecting a data point in the chart drills into detailed results, replacing the main view with a per-respondent table. A "Back to Overview" button restores the high-level chart. All analytics pages fetch data via server-side calls, ensuring load times under three seconds.

Admins click User Management in their sidebar to open a page listing all user accounts in a table. Each row shows name, email, role, and status. Controls allow selecting multiple users for batch role changes or deactivation. An "Invite User" button opens a form to enter a new user’s email and assign an initial role. Submitting sends an invitation email with a sign-up link pre-configured for that role. A separate Roles & Permissions page lets admins define custom roles, add or remove permissions, and save changes, which immediately affect access rules.

## Settings and Account Management

Every user can click Settings in the sidebar to open a personal profile page. The page shows editable fields for name, email, and password. Users can upload or change their avatar image. Below profile fields, there is a section for notification preferences with toggles for email alerts on quiz assignments, reminders, and feedback results. A "Save Changes" button updates the user’s account on the server and displays a confirmation toast. Managers and Executives see an additional subsection for team preferences, where they can adjust default deadlines or group membership settings. Admins see billing or subscription details if advanced plans exist, showing current plan, usage metrics, and a "Download Invoice" link. A "Back to Dashboard" link in the header returns users to their main dashboard view.

## Error States and Alternate Paths

If a user enters incorrect credentials at sign-in, the login form shows an inline error message stating "Invalid email or password." After three failed attempts, the system may display a captcha challenge. During password recovery, if the entered email does not exist, the form displays "Email address not found." When Managers upload a malformed CSV, the modal lists row numbers with specific errors and prevents submission until corrections are made. In the quiz interface, if the network connection drops, a persistent banner alerts "You are offline. Answers will sync when connection is restored." Answers continue saving locally and sync automatically. If a Respondent tries to access a quiz past its due date, the platform redirects them back to My Quizzes and shows a notice that the assignment has expired. Attempting to navigate to a restricted route—such as a Manager trying to access Admin pages—triggers a 403 error page with an explanation and a link back to the user’s dashboard.

## Conclusion and Overall App Journey

In summary, a new user visits the landing page and signs up with email and password, confirms their account, and signs in. Based on their role, they see a clear, role-specific dashboard with navigation to all relevant features. Managers create, schedule, and publish quizzes, upload respondent lists, and review analytics. Respondents view their assigned quizzes, complete timed assessments, and receive feedback. Executives explore high-level reports and Insight Pathways visualizations. Admins manage users, roles, and permissions. Throughout the experience, settings allow profile and notification updates, and robust error handling guides users through any issues. The platform flow seamlessly connects each page, ensuring users can move from sign-up to content creation or quiz completion without confusion or dead ends.
